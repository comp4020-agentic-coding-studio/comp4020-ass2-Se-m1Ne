# Assignment 2 Reflection

## What was the breakthrough that moved the work forward?

The main breakthrough was realising that a course about breaking rules did not need a website that constantly broke them too.

At first, I tried to connect the interface more directly to the picture-book theme. The clearest example was the page-turn transition between Weeks, Lectures and Assessments. I tested several versions and made the effect stronger, but the more visible it became, the more it distracted from simply moving through the course.

Removing the animation was more useful than continuing to improve it. I kept the Previous/Next navigation because it helped the user, but removed the part that existed mainly to demonstrate the theme. This also clarified the direction of the whole site: the course content can misbehave, while the interface stays clear and reliable.

## What did this work change about who I want to be as a software developer?

This project made me want to be more willing to remove work that is technically successful but does not improve the final experience.

It is easy to keep a feature after spending time building it, especially when it works. The page-turn experiment showed me that working code is not enough reason to keep something. I want to make decisions based more on what the user actually gains from a feature.

I also want to use AI development tools in the same way: not just accepting what can be generated, but testing it, comparing alternatives, setting limits, and deciding when the simpler solution is stronger.
